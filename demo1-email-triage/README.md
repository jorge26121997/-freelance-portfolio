# Demo 1 — AI-Powered Email Triage for Logistics

## Problem
Logistics teams receive dozens of emails daily from 
branches, suppliers and carriers. Reading, classifying 
and responding manually wastes hours every week.

## Solution
Automated system that receives emails, classifies them 
by category using Claude AI, logs everything to Google 
Sheets, and sends automatic replies to urgent requests.

## Categories
- Transport Guide
- Urgent Request (auto-reply triggered)
- Administrative
- Other

## Stack
- n8n for workflow orchestration
- Claude API (claude-sonnet-4-5) for AI classification
- Gmail API for email trigger and auto-reply
- Google Sheets for logging and audit trail

## Result
Zero missed emails, automatic categorisation, 
full audit trail, team time freed for operational work.
